# Versioning

Releases follow semantic versioning: 1.2.3, 2.0.0-rc.1, 0.9.0+build.5.

Dependency ranges look like `^3.1.0`, `~=1.4`, `>=2.1,<3` and `1.x`.

The first public release, v0.1.0, was tagged on 2026-11-04. Patch releases such
as v0.1.1 and v0.1.12 never change behaviour. Python 3.9 through 3.13, Node 20,
Ubuntu 24.04 and macOS 15 are tested.
