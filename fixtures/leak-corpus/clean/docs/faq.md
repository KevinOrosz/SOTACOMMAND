# FAQ

**Is there a rule of thumb for skill size?** Keep a skill short enough to read in
one sitting.

**Do I need a lesson plan to onboard a teammate?** No. Run the quickstart together.

**Can someone set this up for me?** Yes, see the link in the `<!-- cta -->` slot of
the README.

**What happens to rules that keep firing?** They become principles in prose, and
the lint rule that enforces them stays in CI.
