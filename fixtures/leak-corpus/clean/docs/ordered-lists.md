# Ordering

Python dicts are insertion-ordered. Time-ordered events go to the run ledger.
Well-ordered sets come up in the proofs appendix, and Key-ordered maps keep
diffs stable. Reverse-ordered output is available with `--reverse`.

An ordered list in Markdown starts with `1.`; someone ordered 3 copies of the
handbook, and the release ordered after review is v0.1.1.
