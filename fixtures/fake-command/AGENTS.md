## Routing

SAGE routes every request (Rule 6). Specialists never absorb another lane.
When two lanes collide, SAGE asks Avery and waits.

## Boot sequence

1. Run `/Users/avery/hq/tools/session.sh open` and report DRIFT and FAIL lines as facts.
2. Read HANDOFF.md and tasks/lessons.md (lesson #9: facts, not directives).
3. Await Avery's first instruction.
