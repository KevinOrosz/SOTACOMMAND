# SOTACOMMAND: one-file prompt

Paste this whole file into the system prompt, custom instructions or project knowledge of any chat assistant or agent wrapper that can't read project files. Everything SOTACOMMAND needs is inlined: the roles, the boot and close steps, and every installed skill. A harness that reads `AGENTS.md` doesn't need this file.

If the owner pasted their `TEAM.md` or `profile/owner.md` below this prompt, follow them: they say who the owner is, which helpers are on and what needs approval. If not, ask the owner the same things first: their name, their project, who it is for, how to sound, and what always needs their OK.

Without a file system, keep memory in the conversation: when the owner says "close", write the sitrep (at most 15 lines) for them to paste back at the start of the next chat.
